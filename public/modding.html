Modding guide

Build a first-person expedition in a single JSON file. Draw rooms with letters, give the letters jobs, and decide what the player must do to escape.

Your first locked door

Copy this into a plain-text file named night-shift.json. Open Mods → Import file on the title screen, choose the file, then select Play mod. Walk to the key and press E. Face the door and press E again to escape.

{
  "format": 1,
  "name": "Night Shift",
  "start": "intake",
  "levels": [{
    "id": "intake",
    "name": "Intake Office",
    "theme": "lobby",
    "objective": "Take the key and leave through the fire door.",
    "map": [
      "#########",
      "#@.K..E.#",
      "#.......#",
      "#########"
    ],
    "markers": {
      "K": { "kind": "pickup", "name": "Take fire key", "gives": "fire-key" },
      "E": { "kind": "escape", "name": "Open fire door", "need": ["fire-key"] }
    }
  }]
}

Try moving K to the other row and placing % in its old spot. Save and import again. The key has moved, and a Veil now watches the route to the exit.

File and level fields

Use JSON with double-quoted strings. Omit comments and trailing commas. Field names and symbols are case-sensitive. A pack has four required fields.

format and name
Use the number 1 for this language version. Give your pack a display name up to 72 characters long.
start and levels
Set start to the ID of the first level. List 1–12 levels in levels. Doors connect levels by ID, so array order can differ from play order.

Every level requires id, name, theme, objective, map, and markers. Give each level a unique ID. IDs and flag names start with a lowercase letter and accept lowercase letters, digits, and hyphens, up to 32 characters. The level name appears in the HUD. The objective can contain up to 240 characters.

Choose a theme from lobby, hotel, pool, pipes, archive, office, garage, arcade, and blackout. Each uses the game’s existing materials and lighting.

Map symbols

Each string draws one row from left to right. Use 3–32 rows and columns, give each row the same width, and enclose the map in walls. Keep interactive tiles accessible from the spawn.

SymbolIn the room
#Wall.
.Open floor.
@Player spawn. Place exactly one per level.
A–ZAn object from this level’s markers. You choose the letters. Repeat a letter to place another copy. Copies share any flag they grant.
!Roaming monster spawn. Add the level’s monster field and exactly one ! together.
%Veil. Looking at its masks for too long is fatal.
&Bellwether. Move quietly or stay still after its warning knocks.

Choose a roaming monster from bacteria, hound, smiler, crawler, watcher, and partygoer. A Crawler hunts by sound. A Watcher freezes under observation. To tune pursuit, add a numeric speed from 0.5 to 6 alongside monster. A level supports up to six resident creatures in addition to its roaming monster.

Marker language

Each marker takes a kind and an optional model. All interactive markers require a name up to 72 characters for the interaction prompt. A prop uses only kind and an optional model.

KindBehavior and fields
pickupAdds an item to inventory. Requires one gives flag.
switchActivates once and grants its required gives flag.
codeOpens a keypad. Requires code and gives. Use a string up to 32 characters, such as "0417". Matching ignores case and surrounding spaces.
noteShows its required text each time the player reads it.
hideHiding place. Interact again to leave.
exitLeads to another level. Requires to with the destination ID.
escapeFinishes the mod and records the escape.
propPlaces scenery such as a shelf or chair.

Flags are shared across a pack’s levels. "gives": "power-on" records a flag. "need": ["power-on", "brass-key"] requires both flags. A pickup, switch, keypad, exit, or escape can have up to 16 required flags. Pickups, switches, and keypads can also show optional completion text up to 240 characters long. Grant torch to enable the flashlight with F.

To connect two levels, place a letter on the first map and define it as {"kind":"exit","name":"Take lift","to":"basement"}. Add a second level with "id":"basement" and an escape marker. Add a return exit if your puzzle requires backtracking.

Available models are key, flashlight, note, door, elevator, terminal, breaker, locker, shelf, desk, chair, crate, barrel, plant, valve, and sign. Omit model to use the kind’s default.

Test and share

Use Load sample to play Dead Letter Office, or download its JSON above. It demonstrates a key, a lift, a Bellwether, and a keypad with an in-world clue. Play your own route from spawn to escape, including wrong codes, locked doors, and any one-way exits.

Import errors identify the field or map location to fix. For an undefined tile, add the matching uppercase marker or replace the tile with a period. For an unreachable escape, check the destination IDs, flag spelling, and the order in which the player can activate each object. Each file can be up to 128 KiB and each level can use up to 96 letter tiles.

Share the JSON file. Other players import it from the same Mods menu. The browser remembers the last imported pack and keeps its checkpoint separate from the main campaign and other mods. Reimport an earlier file to resume it. Editing the pack’s data starts a separate save, and changing only JSON indentation preserves the checkpoint.
